# 🌍 Planet Earth Website

A responsive and customizable multi-page website template themed around creativity and digital services, titled **Planet Earth**. The project showcases web design, graphic design, and content creation services with a modern layout, Bootstrap components, and rich styling.

🔗 **Live Demo:** [View on GitHub Pages](https://dhruvesh1811.github.io/planet-earth/)

## ✨ Features

- Responsive layout using Bootstrap 5
- Custom font and color selectors for easy styling
- Font Awesome integration for icons
- Multiple preloaded font families via Google Fonts
- Contact form layout (no backend integration)
- Elegant animations and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3
- Google Fonts
- Font Awesome
- jQuery (for potential interactivity)
- Responsive design principles

## 🚀 How to Use

1. **Clone or Download** the repository.
2. **Open `index.html`** in any modern browser.
3. Customize the fonts and colors using the off-canvas sidebar in the UI.
4. Replace placeholder content and images in the `/img` directory as needed.

## 📌 Customization Notes

- Update `index.css` to modify the theme's colors, hover states, or layout.
- Modify the `img/` directory to include your own branding and service visuals.
- The site is static; to make the contact form functional, integrate with a backend or a service like Formspree.
